Build Plan (in order)

Phase 1 — Foundation (Steps 2, 5, 6)

1. python -m venv venv → activate → pip install fastapi "uvicorn[standard]" sqlalchemy alembic pandas → pip freeze > requirements.txt

2. config.py reads DATABASE_URL from .env (PostgreSQL)

3. database/connection.py: engine + sessionmaker; tables.py: two tables:

- logs: id PK, timestamp, source_ip, destination_ip, event_type, severity, raw_message, parsed_data JSONB, created_at

- threat_alerts: id PK, log_id FK→logs.id, threat_type, threat_score, description, is_resolved, created_at

4. alembic init, point env.py at your MetaData → generate initial migration

Phase 2 — Parsing (Step 3)

5. Each parser returns a normalized dict: timestamp, src/dst IP, event_type, severity; log_parser.py auto-detects format

Phase 3 — Real-time pipeline (Steps 4, 10)

6. websocket/manager.py: track connections, broadcast(event_type, payload)

7. Pipeline flow: WS/HTTP ingest → parser → DB insert → detector → score → alert stored → broadcast new_log + threat_alert

Phase 4 — Detection (Steps 7–9)

8. Rules: ≥5 failed logins/IP/min (+30), blacklisted IP (+50), port scan pattern (+40), repeated firewall blocks/IP (+20); sum capped 0–100 → Low/Medium/High/Critical bands

9. Anomaly: per-IP deque sliding window of timestamps → rolling mean ± 3σ on connection frequency

Phase 5 — REST routes (Steps 11–12)

10. Wire up the 6 endpoints listed above with Pydantic response models and severity/date filters

Run command: uvicorn main:app --reload --port 8000
